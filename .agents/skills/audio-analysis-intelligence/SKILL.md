# audio-analysis-intelligence

## Scope and execution
1. Obtain actual source material and inspect format, sample rate, channels, clipping, duration, and processing provenance.
2. Prefer verifiable measurements: peak, RMS, energy over time, onset strength, stereo correlation, spectrum, and silence boundaries.
3. Treat key, BPM, downbeat, instrument identification, section boundaries, and perceptual emotion as probabilistic hypotheses unless independently verified.
4. Include precise timestamp/evidence references for significant observations; account for halftime or doubletime ambiguity.
5. Compare revisions using identical source ranges, loudness-normalized listening where possible, and objective waveform/dynamic evidence.
6. Suggest the highest-value musical and production changes with exact notes, rests, frequency regions, or arrangement events when supported.
7. Never claim precise transcription, source separation, or hearing tests from file metadata alone.

## Skill coordination
Use other installed specialists only if actually available. Do not rely on undocumented device capabilities or claim tools/tests succeeded without running them. Preserve user projects and copyrighted material.

## Output
Give an actionable deliverable, explicit assumptions, sources for externally verified facts, and QA statuses of PASS, FAIL, NOT RUN, or MANUAL REVIEW REQUIRED.
